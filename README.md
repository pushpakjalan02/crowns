# Crowns 👑

An endless, offline queens logic puzzle (in the style of LinkedIn's "Queens"), built as a Progressive Web App.

- **Play now (locally):** double-click `app/index.html`
- **Understand, test, launch:** [docs/GUIDE.md](docs/GUIDE.md)
- **How it was built, step by step, with troubleshooting:** [docs/BUILD_JOURNAL.md](docs/BUILD_JOURNAL.md)

Rules: place one crown in every row, every column and every colour region. Crowns may not touch, not even diagonally.
